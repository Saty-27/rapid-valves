# Rapid Valves (India) Limited — Corporate Industrial Website

> **Always in Control.**  
> High-performance industrial flow control systems for Marine, Naval Defence, Oil & Gas, Steel, Power Generation, and Process Industries.

---

## 🌟 Overview

A modern, high-performance, single-page B2B corporate web application for **Rapid Valves (India) Limited** (NSE & BSE Listed). Built with precision engineering aesthetics, fluid Apple-grade micro-animations (`cubic-bezier(0.22, 1, 0.36, 1)`), and authentic industrial imagery.

---

## 🚀 Key Features & Architectural Sections

- **Global Sticky Navbar**: Seamless scroll transition from transparent video overlay to white sticky header with brand red accents and fluid bottom wave contour.
- **Cinematic Full-Screen Hero**: True full-width, edge-to-edge video banner with hardware-accelerated safe parallax and integrated media controls.
- **Organic Wave Transition**: Elegant SVG wave line connecting the Hero video to the About section.
- **About Rappid Valves**: Executive company overview with 4 core feature badges and staggered photography cards.
- **Industries We Serve**: 10 authentic industrial sectors (Shipbuilding, Naval Defence, Oil & Gas, Steel Mills, Water Treatment, Distillery, Power, Chemical, Pharma, Renewable Energy) with dynamic hover elevations.
- **Our Products / Systems**: 6 engineered valve systems (Gate, Globe, Check, Ball, Butterfly, Marine & Control) with diagonal technical panel cutlines, pop-in numbering, and specifications.
- **Certifications & Approvals**: Verified credential panel featuring ISO 9001:2015, MSME, GST, IEC, Incorporation, and IBR approvals with interactive detail modal.
- **Investor Highlights & Global Presence**: Dynamic revenue growth bar charts with animated counters and real-time Great Circle flight route drawings from India HQ to worldwide export destinations.
- **Project Gallery**: Asymmetric editorial masonry showcase with high-resolution lightbox modal.
- **Continuous 5-Stage Manufacturing Process**: Synchronized pipeline progress bar tracking Quotation, Drawings, GAD, Approval, and Production.
- **Managing Director’s Message**: Leadership statement from Gaurav Dalal with framed quote, signature, and corporate credentials.
- **Engineering Insights / Blog**: 6-card intelligence hub with categorized technical insights and full reading modal.
- **Technical FAQs**: 15-question categorized accordion with smooth CSS grid expansion (`0fr` → `1fr`).
- **Architectural Brand Crown Footer**: Spacious 5-column layout with raised red brand crown, corporate filings, quick quotation CTA, and trust strip.
- **Rappid AI Engineer & Floating Dock**: WhatsApp quick connect, direct sales hotline, and interactive AI flow assistant with preconfigured queries and live chat stream.

## 💻 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Saty-27/rapid-valves.git
   cd rapid-valves
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build locally:
   ```bash
   npm run preview
   ```
